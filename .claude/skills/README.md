# Skills du projet

Guides chargés par Claude Code quand la tâche s'y prête (design, animation, rendu mobile).

## Emil Kowalski — skills de design et d'animation

Source : https://github.com/emilkowalski/skills (commit 2d22863), licence MIT
(`LICENSE-emilkowalski-skills`). Fichiers copiés tels quels.

Retenus pour Assokit :

| Skill | Pour quoi dans Assokit |
|---|---|
| `animate-expo` | Appli Expo / React Native (`mobile/App.js`) : retours au toucher, feuilles, transitions, haptique |
| `mobile-native` | Pages du site affichées dans la WebView de l'appli et sur téléphone |
| `break-ui` | Écrans testés avec des données extrêmes (noms longs, e-mails, gros montants, listes vides) |
| `emil-design-eng` | Finition générale de l'interface (site et appli) |
| `apple-design` | Principes iOS : gestes, ressorts, matières, typographie, mouvement réduit |
| `find-animation-opportunities`, `improve-animations`, `review-animations` | Audit et revue des animations |
| `animate`, `animation-performance`, `animation-vocabulary` | Animations CSS du site |

Non retenus (sans objet ici) : `write-swift` (pas de code Swift), `ask-sonner`, `pick-ui-library`
et `prototype` (bibliothèques React web : le site est en PHP).
