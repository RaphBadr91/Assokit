Intègre Assokit à un site WordPress d'association.

== Description ==
Affichez vos événements et projets publics Assokit dans WordPress, et un bouton
vers l'espace adhérent. Shortcodes : [assokit_evenement], [assokit_projet],
[assokit_espace], [assokit_bouton]. Réglages : Réglages → Assokit.

À venir (avec le paiement en ligne Assokit) : formulaires d'adhésion et de don
embarquables.

== Installation ==
1. Copier le dossier `assokit/` dans wp-content/plugins/ (ou installer le .zip).
2. Activer le plugin.
3. Réglages → Assokit (URL par défaut https://assokit.fr).
